# 📂 Smart File Organizer

A Python application that automatically organizes files into categorized folders based on their file extensions. It helps keep directories clean by sorting files into folders such as Images, Videos, Documents, PDFs, Music, Archives, Python, and Others.

---

## ✨ Features

- 📁 Automatically organizes files into categories
- 🖼️ Supports Images, Videos, Documents, PDFs, Music, Archives, and Python files
- 📂 Automatically creates folders if they do not exist
- 🔄 Prevents duplicate files by renaming them automatically
- 📝 Generates a log file of all moved files
- 📊 Displays a summary after organization
- 🖥️ Includes both CLI and GUI versions
- ⚡ Fast and lightweight
- 💻 Works on Windows, Linux, and macOS

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yashjodon/Smart-File-Organizer.git
```

Go to the project folder

```bash
cd Smart-File-Organizer
```

Run the CLI version

```bash
python main(CLI).py
```

Or run the GUI version

```bash
python main(GUI).py
```

---

## 📖 How It Works

1. Select or enter the target folder.
2. The program scans all files.
3. Files are categorized by extension.
4. Required folders are created automatically.
5. Files are moved safely.
6. Duplicate filenames are handled automatically.
7. A summary and log file are generated.
